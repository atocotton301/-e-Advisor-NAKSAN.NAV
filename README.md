# [e-Advisor] NAKSAN.NAV

AI 기반 전공트랙 추천 및 학기별 이수 로드맵 서비스.

한성대학교 학생의 이수 내역과 관심사를 바탕으로 전공트랙을 탐색하고, 졸업까지의 교과·비교과 계획을 세울 수 있도록 돕는 학업 내비게이터를 목표로 합니다.

## 현재 진행 상태

기획 및 수요 검증 단계입니다. 아래 기능은 개발 예정이며, 아직 실행 가능한 서비스 코드는 포함되어 있지 않습니다.

## 핵심 기능 계획

| 모듈 | 예정 기능 |
| --- | --- |
| SCAN | 이수 내역·성적·관심사 입력 |
| MATCH | 전공트랙 적합도 Top 3 추천 및 추천 근거 제공 |
| ROUTE | 졸업까지 학기별 교과·비교과 이수 로드맵 생성 |
| CHECK | 졸업요건·선수과목·학점 충족 현황 점검 |
| ASK | 학사 규정과 출처를 바탕으로 한 AI 상담 |

웹과 모바일 앱이 하나의 백엔드 API를 공유하는 구조를 계획하고 있습니다.

## 우선 진행할 작업

- 재학생 설문으로 학업·진로 정보의 불편사항과 기능 우선순위 확인
- 트랙·교과·졸업요건 자료 수집 및 데이터 구조 설계
- SCAN 입력과 CHECK 요건 점검부터 프로토타입 개발
